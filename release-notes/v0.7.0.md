## Claude Code tool style (opt-in)

Set `"toolStyle": "claudecode"` in `pi-pretty.json` (default: `default`, unchanged) for a Claude Code-like transcript:

- Collapsed tools become `✓ Name (args)` with an `└` result row: line counts, duration, bash `timeout`, and `+N -N` (green/red) for edits. A spinner shows while running, `·` while pending, `✗` on failure.
- Consecutive tool calls fold into `Done (…)` / `Running (…)` groups; click a tool in a group, or press Ctrl+O, to expand it. Hints show your own key bindings.
- Covers `read`, `bash`, `grep`, `find`, `ls`, and — without re-registering them — `write`, `edit`, `apply_patch` (pi-diff), `codemode`, and `recall` (pikit). Full output is still there when expanded.
- Hidden thinking reads `thought 3s (ctrl+t to expand)`; user messages drop the `❯` prefix; the input box uses plain rules with a flush-left `❯`.

### Verification

- 325 tests passing across 21 files; typecheck passing; no new lint errors (existing warnings remain).
- Checked in a live Pi session for `read`/`bash` rows, grouping, `write`/`edit` rows and expansion. `apply_patch`, `codemode`, and `recall` styling and the thinking/expand hints are covered by tests but have had less live exposure.

### Known limitations

- The style patches Pi's `ToolExecutionComponent` and chat `Container` render lookups, which are not public API. If Pi changes them, styling falls back to Pi's own rendering.
- Expanded `write`/`edit`/`apply_patch`/`codemode` output loses the shell's background box.
- While a `codemode` script runs, its per-call progress list is replaced by a spinner until it finishes.

This GitHub release does not publish the package to npm.
