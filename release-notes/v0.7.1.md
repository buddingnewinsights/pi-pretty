## Fixes

- `toolStyle: "claudecode"`: expanding a collapsed `read`, `bash`, `find`, `grep`, or `ls` result kept falling back to plain text. The original renderer is now handed only its own previous component, so syntax highlighting and line-number gutters are kept (#14).
- Windows: `pi-pretty.json`, `settings.json`, and the FFF data directory are found when `HOME` is unset, via an `os.homedir()` fallback. Previously the config was silently ignored (#16).
- `ls` tree view shows a per-type Nerd Font icon for files, and keeps the SDK's `[N entries limit reached…]` notices below the tree (#15, thanks @october2823).

## Maintenance

- Remove `bun.lock`; the project uses npm.
- Development SDK and TypeScript bumped (Pi 1.3.0, TypeScript 7); runtime peer ranges are unchanged.

### Verification

- 332 tests passing across 22 files; typecheck passing; no new lint errors.
- The `claudecode` expand fix and the `HOME` fallback are covered by regression tests that fail without the fix; neither was checked on a live Windows machine.
